# Roadmap

| Milestone | State |
| --- | --- |
| 0 Environment audit | Done |
| 1 Minimum playable (car, camera, road, collision, controls) | Done |
| 2 Driving quality | Partial: acceleration, brake, reverse, handbrake, suspension, HUD done. Drift tuning, real gearbox, gamepad not done |
| 3 World | Partial: one region with terrain, road loop, forest. No junctions, towns or landmarks |
| 4 Racing (checkpoints, AI, results) | Not started (checkpoint data exists on Track) |
| 5 Game loop (events, rewards, garage, saves) | Not started |
| 6 Presentation (menus, minimap, weather, day/night cycle, audio, settings) | Partial: time-of-day presets and bloom only |
| 7 Content expansion | Not started |
| 8 QA and optimization | Ongoing |
| 9 Release packaging | Not started (static web build works) |

## Next priorities
1. Milestone 4: checkpoint race logic, countdown, AI opponents following the track spline, results.
2. Drift and grip tuning, a proper gear/RPM model, gamepad input.
3. Main menu, pause menu, settings (graphics presets), save data.
4. Audio (Web Audio engine synth, tyres, impacts).
5. Bigger road network with junctions and more regions.
6. Visual quality: grass and roadside detail, guard rails, better tree models, car interior.
